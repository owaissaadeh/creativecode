نظام إدارة المحتوى الكامل

أنشئ نظام CMS داخلي باستخدام Model واحد موحد:

PageSection Model:

- page (home/services/ai/projects/blog/contact/consultation)
- section_key (hero/about/services_preview/ai_section/projects_preview/clients/cta/footer/etc)
- title
- subtitle
- content
- image_url
- button_text
- button_link
- order
- is_active

كل صفحة عامة يجب أن:
- تجلب محتواها من PageSection
- ترتب الأقسام حسب order
- تعرض فقط is_active = true

لا تكتب أي نص ثابت داخل EJS
كل النصوص يجب أن تكون ديناميكية من قاعدة البيانات
